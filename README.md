# 🧊 Glacier Size & Ice Trend Analysis (NASA/NOAA NSIDC)

This project explores real-world glacier datasets from NASA and NOAA to analyze glacier size distributions and approximate ice trend behavior using machine learning techniques.

---

## 🌍 Data Sources

- NASA Open Data Portal  
  "Largest glaciers and glacier complexes in the world, version 1"  
  https://data.nasa.gov/dataset/largest-glaciers-and-glacier-complexes-in-the-world-version-1-75379

- NOAA / NSIDC G10037 Cryosphere Dataset  
  https://noaadata.apps.nsidc.org/NOAA/G10037/

---

## 🎯 Objectives

- Analyze glacier and glacier complex size distributions  
- Combine multiple cryosphere datasets  
- Apply clustering and classification techniques  
- Build a simplified trend approximation model  
- Explore ice mass variability patterns  

---

## ⚠️ Important Note

The dataset is a spatial snapshot and not a true time series.  
A synthetic time index is used to approximate trend behavior for analytical and educational purposes.

---

## 🧠 Methods Used

- Pandas for data processing  
- NumPy for feature engineering  
- Linear Regression for trend estimation  
- K-Means clustering for pattern discovery  
- Random Forest for classification experiments  
- Matplotlib for visualization  

---

## 📊 Outputs

- Glacier size distribution analysis  
- Ice trend approximation (shrinking vs stable)  
- Cluster-based grouping of glacier sizes  
- Visual exploration of cryosphere structure  

---

## 🚀 Goal

To demonstrate how real cryosphere datasets from NASA/NOAA can be used in machine learning pipelines for exploratory climate and Earth observation analysis.
